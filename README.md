## ATT-DEF-win10-Kerberoasting

(AD) - это служба каталогов от Microsoft, которая предоставляет централизованное управление и хранение информации о пользователях, компьютерах, службах и других ресурсах в сети Windows.

SPN (Service Principal Name) - уникальный идентификатор службы в AD, который связывает экземпляр службы с учетной записью для аутентификации через Kerberos.

Билет (Ticket) в Kerberos — это цифровой пропуск, который подтверждает твою личность. Это зашифрованный файл данных, который выдается Центром распределения ключей (KDC, обычно это Контроллер Домена).

Rubeus — это инструмент для работы с протоколом Kerberos в Windows-сетях (Active Directory).
Если говорить просто: это «швейцарский нож» для атак и аудита на основе билетов Kerberos.
Что он умеет (основное):
Kerberoasting (то, что ты пытался сделать): Вытаскивает тикеты сервисных учетных записей, чтобы потом взломать их пароли офлайн.
AS-REP Roasting: Ищет пользователей, у которых отключена преаутентификация Kerberos, и получает их хеши без знания пароля.
Pass-the-Ticket: Позволяет использовать украденные билеты Kerberos для доступа к другим ресурсам без пароля.
Silver/Golden Ticket: Создание поддельных билетов для получения прав администратора домена.
Delegate attacks: Атаки через делегирование (Unconstrained/Constrained Delegation).

Как работает Kerberoasting:
Запрос TGS-билета: Злоумышленник запрашивает билет службы (TGS) для учетной записи с зарегистрированным SPN
Шифрование: Билет шифруется хешем NTLM пароля учетной записи службы
Офлайн-взлом: Полученный билет можно взламывать офлайн без взаимодействия с контроллером домена
Результат: Успешный брутфорс раскрывает пароль служебной учетной записи
